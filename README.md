# Cognita

**Cognita** is an AI assistant designed to help with professional writing, academic work, document preparation, research, analysis, and general problem solving.

## Features

- **Document drafting and editing**: Create, refine, and format reports, essays, memos, and proposals.
- **Research assistance**: Summarize literature, locate sources, and organize citations.
- **Data analysis support**: Explain statistical concepts, interpret results, and prepare charts.
- **GitHub workflow help**: Create branches, commits, pull requests, and issues.
- **Project guidance**: Best practices for project management, timelines, and workflows.

## Getting Started

To use Cognita, simply start a conversation. No installation required — just ask me what you need help with!

I can help with tasks such as:
